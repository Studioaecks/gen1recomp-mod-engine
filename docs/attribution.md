# Attribution guide

Every mod and every tool derived from or targeting Gen1Recomp **must** include this credit:

```
Based on the Pokemon Gen 1 Recompilation Project by BOIS CLUB GAMES, LLC
(https://github.com/bryanthaboi/gen1recomp)
```

Places it must appear:

- README.md (or equivalent project page)
- In-app credits, About screen, or title screen if you build a launcher
- Any launcher, front-end, or menu shell that starts the game
- Source comments in generated main.lua files

Keep the original LICENSE file and copyright notices when forking.
