XENO-MOD

Alien-intelligence mod engine for Gen1Recomp

A practical toolkit for scaffolding, visually editing, packaging, and distributing mods for the Pokemon Gen 1 Recompilation Project.

View on GitHub · Download ZIP

Features

  • Godot-style visual editor (XENO-MOD) with map lattice, inspector, and code strand
  • Desktop-launchable shortcuts for Windows, macOS, and Linux
  • Automatic attribution and changelog
  • Predictive templates, sprite importer, map presets
  • AI-assisted snippets via optional xAI API
  • Pure Lua mods that run on every Gen1Recomp platform

Clone or download, then run python3 ModEngine.py or the platform shortcut to launch the editor.

Based on the Pokemon Gen 1 Recompilation Project by BOIS CLUB GAMES, LLC
